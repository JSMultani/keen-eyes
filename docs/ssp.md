# System Security Plan Content

This document is a starter SSP narrative for Keen Eyes deployments. It must be reviewed and completed by the organization operating the system.

## System Description

Keen Eyes is a local-first developer platform that orchestrates TDD workflows, validation checks, and evidence generation for software changes.

## Boundary

The system boundary includes the orchestration process, local project workspace, scanner outputs, policy files, and generated evidence artifacts. External model providers, CI runners, and Git forges must be documented separately when used.

## Control Implementation Notes

Keen Eyes can provide supporting evidence for access control tests, audit log verification, configuration checks, vulnerability scanning, and secure development practices. Interview and final assessment objectives require human review.
